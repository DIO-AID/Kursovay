# Промт: Интеграция репозиториев в проект

Скопируй этот промт и отправь любому ИИ (DeepSeek, ChatGPT, Claude).

---

У меня есть папка `C:\проект\Гиты\` со скачанными репозиториями. Я хочу понять, какие из них стоит интегрировать в мой проект и как это сделать.

**Мой проект:** рабочий файловый проект разработчика. Использую opencode (AI-агент для CLI), codegraph (индексатор кода), Obsidian для заметок, Node.js. Планирую переход с Windows на Arch Linux.

**Репозитории:**

1. **free-claude-code** — https://github.com/Alishahryar1/free-claude-code
   Прокси для бесплатного Claude Code через сторонние модели (11 провайдеров)

2. **agentmemory** — https://github.com/rohitg00/agentmemory
   Долговременная память для AI-агентов. Сохраняет контекст между сессиями

3. **CloakBrowser** — https://github.com/CloakHQ/CloakBrowser
   Stealth-браузер, проходит Cloudflare/reCAPTCHA. Для парсинга сайтов

4. **academic-research-skills** — https://github.com/Imbad0202/academic-research-skills
   13 AI-агентов для написания научных статей (обзоры, факт-чекинг, APA-отчёты)

5. **codegraph** — https://github.com/colbymchenry/codegraph
   УЖЕ УСТАНОВЛЕН (npm global + opencode MCP + проиндексирован проект)

6. **financial-services** — https://github.com/anthropics/financial-services
   50+ AI-агентов для финансов: DCF-модели, инвестбанкинг, PE, equity research

7. **claude-tips** (статья, не репозиторий)
   10 приёмов экономии токенов Claude

---

Для каждого репозитория:
1. Прочитай README и структуру файлов
2. Оцени, нужен ли он в моём проекте (да/нет и почему)
3. Если да — напиши пошаговый план: зависимости, установка, настройка, интеграция
4. Если нужен только частично — что именно стоит взять

После анализа всех — покажи итоговую таблицу: что ставить, что пропустить, порядок действий.
