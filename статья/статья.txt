## Введение

В настоящее время методы машинного обучения становятся всё более популярными благодаря росту доступных вычислительных ресурсов. Многие промышленные процессы оцифрованы, и для них создаются цифровые двойники, которые позволяют прогнозировать поведение системы на основе больших объёмов ретроспективных данных. Среди наиболее популярных моделей с высокими прогностическими качествами и устойчивостью к неоднородности обучающих данных выделяется семейство ансамблевых моделей. Одним из их представителей является модель **CatBoost**, которая использует бинарные деревья решений в качестве базовых предикторов и позволяет работать с категориальными признаками.

Также, из-за возможного наличия большого числа факторов, влияющих на прогнозируемый показатель, необходимо использовать методы, улучшающие качество отбора этих показателей. Один из подходов — использование алгоритмов, оценивающих заданный функционал качества построения прогноза, например, алгоритм **SHAP**, который использует перестановку факторов для определения наиболее значимых.

Однако для улучшения качества прогноза часто бывает полезно добавлять различные модификации факторов: логарифм, квадрат, обратное представление фактора и т.п. Этот подход искусственно создаёт проблему **мультиколлинеарности** факторов, что снижает выбранную метрику качества прогноза.

**Цель исследования** — построение модифицированного алгоритма на основе классической схемы SHAP для оценки важности факторов в модели CatBoost.

## Ансамблевые модели машинного обучения

При работе с большими объёмами данных могут возникать проблемы: высокая дисперсия (модель чувствительна к изменчивости входных признаков), низкая точность отдельной модели, шум и смещённость оценок. Ансамблевые модели позволяют комбинировать несколько моделей в процессе прогнозирования и выбирать лучшую на основе заданной статистики.

Основные типы ансамблевых моделей:

- **Бэггинг** (например, Random Forest) — построение бутстреп-выборок и параллельное обучение моделей.
- **Бустинг** — последовательное построение модели на основе нескольких слабых моделей с учётом минимизации ошибок предыдущих моделей (XGBoost, LightGBM, CatBoost).
- **Стэкинг** — обучение базовых алгоритмов на разных частях выборки, их ответы интерпретируются как новые признаки.
- **Блендинг** — разновидность стэкинга, где выборка делится на две части.

## Модель CatBoost

Модель **CatBoost** (categorical boosting) предложена компанией Yandex в 2017 году. Она представляет собой улучшенную модель бустинга, способную работать с категориальными признаками.

**Постановка задачи:**  
Дана обучающая выборка  

\[
D = \{(x_k, y_k)\}_{k=1,\dots,n},
\]  

где \(x_k = (x_k^1, \dots, x_k^m)\) — вектор факторов, \(y_k \in \mathbf{R}\) — значение отклика. Требуется найти функцию \(F: \mathbf{R}^m \to \mathbf{R}\), минимизирующую ожидаемые потери.

Градиентный бустинг строится итеративно:

\[
F^t = F^{t-1} + \alpha h^t
\]

Функция \(h^t\) выбирается из семейства \(H\) так, чтобы аппроксимировать отрицательный градиент. CatBoost использует бинарные деревья решений, где разбиение пространства признаков происходит по пороговым значениям атрибутов.

## SHAP-алгоритм для определения важности факторов в CatBoost

Для интерпретации сложных моделей используется модель объяснения, аппроксимирующая исходную модель. Один из подходов — метод Шепли, который требует переобучения модели на всех подмножествах признаков. Каждому признаку присваивается значение важности, отражающее эффект от включения этого признака.

Практическая реализация — **SHAP**.

---

## Модифицированный SHAP-алгоритм

В некоторых задачах машинного обучения используются различные модификации факторов (квадрат, корень, экспонента, логарифм) для увеличения предсказательной силы моделей. Однако это усиливает мультиколлинеарность.

Для устранения этого эффекта предлагается алгоритм отбора значимых факторов модели CatBoost, который возвращает набор факторов, содержащий наиболее влиятельные входные переменные с учётом их возможных модификаций.

### Алгоритм (псевдокод, описание):

1. Вход: обучающая выборка \(\{(x_i, y_i)\}\), порог \(t \in [0,1]\).
2. Обучается модель CatBoostRegressor.
3. Вычисляются значения важности признаков.
4. Вычисляются веса (важность / сумма важностей).
5. Отбираются веса > порога \(t\).
6. Циклически для каждого отобранного признака:
   - Если это первый признак: удаляются все его модификации из обучающей выборки.
   - Иначе: переобучается модель, снова вычисляются важности, снова отбор по порогу, удаляются модификации текущего признака.
   - Текущий признак добавляется в итоговый список.
7. Возвращается список отобранных факторов.

Алгоритм позволяет оставить только одну модификацию из нескольких для каждого исходного фактора, устраняя искусственную мультиколлинеарность.

## Вычислительные эксперименты

Использовался набор данных о процессе выплавки стали в доменной печи, содержащий **980 факторов** (98 исходных параметров и их различные модификации). Объём массива — **480 261 строка**.

Проведена серия экспериментов для **94 различных моделей**. В статье приведены результаты для одной из моделей (таблица).

**Порог включения фактора в модель:** 0.1.

**Сравнение:**

- Стандартный SHAP: коэффициент детерминации \(R^2 = 0.6912\)
- Модифицированный подход: \(R^2 = 0.7125\)

Факторы в модифицированном подходе представлены в порядке убывания важности с указанием конкретных модификаций (например, «Factor 82», «Factor 6, transformation 6» и т.д.). Некоторые факторы, определённые в обоих подходах, выделены в таблице.

### Выводы эксперимента:

- Предложенный подход позволяет улучшить прогностические качества модели по заданному критерию (например, коэффициент детерминации).
- Устраняется проблема мультиколлинеарности, искусственно созданной модификациями факторов.
- Недостаток: увеличенное время выполнения из-за большего числа переобучений.

## Заключение

В исследовании предложен подход к определению наиболее значимых факторов для построения модели CatBoost. Алгоритм основан на классической схеме SHAP, дополненной возможностью учёта различных модификаций факторов и использованием в финальной модели только **одной** модификации из нескольких.
