# Отчёт по экспериментам: выбор модификаций признаков

> Файл создан `scripts/report.py` — не редактировать вручную. Графики: `results/figures/*.svg`, таблица: `results/summary.csv`.

Результаты: 3 датасет(ов), коммит(ы) кода 47ada61, прогоны 2026-09-28 … 2026-09-28.

**Как читать.** Δ — разница средних R² с «Все модификации» на одних и тех же фолдах. p — парный тест Уилкоксона, p_holm — с поправкой Холма внутри блока «датасет × модель». ▲/▼ — значимо лучше/хуже (p_holm < 0.05 и |Δ| ≥ 0.005); ≈ — значимо, но разница меньше 0.005 (практически нет); пусто — различие не доказано.
