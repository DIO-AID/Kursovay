# Решения

Правило: **критерий принятия записывается до прогона**. Вывод по методу — только
по этому критерию, по цифрам из `docs/REPORT.md` / `results/summary.csv`.
Если критерий меняется — это отдельная запись с датой и причиной, старые выводы пересчитываются.

## Как считаются вердикты (общее для всех критериев)

- Сравнение с опорным методом `base_fe_all` (все 5 модификаций всех факторов, без отбора)
  на одних и тех же фолдах, парный тест Уилкоксона.
- Поправка Холма на множественные сравнения внутри блока «датасет × модель».
- ▲ / ▼ — p_holm < 0.05 **и** |ΔR²| ≥ 0.005; ≈ — значимо, но |ΔR²| < 0.005
  (практически без разницы); пусто — различие не доказано.
- Общий рейтинг: средние ранги по блокам «датасет × модель», тест Фридмана,
  критическая разница Неменьи (α = 0.05).

## Критерий A — синтетика (этап 1)

Задан в цикле 1, уточнён 2026-09-28 (вердикты стали строже: Холм + порог 0.005).
Метод **принимается**, если на обеих синтетиках (`synth_indep`, `synth_corr`) одновременно:

1. нет ▼ хотя бы на 2 из 3 моделей;
2. признаков в среднем не больше половины от `base_fe_all` (≤ 25 из 50);
3. стабильность отбора (средний Жаккар между фолдами) ≥ 0.8.

Дополнительно для выбора формы: **«восстанавливает форму»**, если доля верной модификации ≥ 0.8.

## Критерий B — реальные данные (этап 2, ветка `research/real-data`)

Зафиксирован 2026-09-28, **до** прогона на реальных датасетах. 10 датасетов из `docs/PLAN.md`,
выборка 10 000 строк для больших, разбиение по времени для Power Plant, Gas Turbine, Steel.
Метод считается **полезным на реальных данных**, если:

1. на Ridge и на MLP нет ▼ хотя бы на 7 из 10 датасетов;
2. в общем рейтинге (10 датасетов × 3 модели = 30 блоков) средний ранг лучше, чем у `base_fe_all`;
   «значимо лучше» — только если разница рангов больше CD Неменьи, иначе «не хуже»;
3. признаков в среднем не больше половины от `base_fe_all`;
4. медианная по датасетам стабильность ≥ 0.6.

Для бустинга по H0 ожидается «≈ / пусто»; ▼ на бустинге — повод разобраться, но не отказ.
Для датасетов без известной истины «верная форма» не оценивается.

## Журнал

### 2026-09-28 — `research/main` собран, цикл 1 воспроизведён

Весь цикл 1 перезапущен на новой структуре (`scripts/run.py --method all`,
`scripts/theory_check.py`, `scripts/report.py`). Все R², число признаков, стабильность,
восстановление истины, ранги (2.33 … 8.00), Фридман p = 4.5e-5 и CD = 3.50 совпали с циклом 1.

Что изменилось в выводах из-за строгих вердиктов: выигрыш на бустинге (+0.0016…+0.0018)
теперь «≈», а не ▲; у «Формы зависимости» на Ridge +0.0002 — тоже «≈».
Значимый выигрыш у отбора остался только на MLP (+0.013…+0.017). Это честнее и
согласуется с H0: бустингу форма безразлична, отбор ему почти ничего не даёт.

**Рейтинг** (9 блоков): форма 2.33, групповая важность 2.78, RFE 3.89, все модификации 4.22,
Boruta 4.56, исходные 5.11, Сысоев испр. 5.11, Сысоев статья 8.00; CD = 3.50.
Значимо отличается только «Сысоев (статья)»: он хуже формы, групповой важности, RFE и
«всех модификаций» (разница рангов > 3.50). Остальные методы между собой статистически
не различимы. Блоков мало, рейтинг предварительный — нужны реальные данные.

**Отрицательный результат: `diabetes`** (442 строки). Ни один метод отбора не лучше
`base_fe_all` на Ridge и бустинге; стабильность отбора 0.27–0.41. На малой выборке
отбор нестабилен, выигрыш не подтверждается.

**Известные ограничения `shape_fit`** (задачи для `research/shape-fit`):
- предполагает аддитивность (модель без взаимодействий);
- выбор формы хрупкий при слабой кривизне: x4 sqrt 0.971 против raw 0.963; на `diabetes`
  (признаки отнормированы в узкий диапазон, после сдвига все формы почти линейны)
  s5 inv 0.880 против raw 0.877 — выбор по сути случайный. Нужен критерий запаса (BIC, бутстрэп).

Мелкие правки кода: `shape_fit` теперь сохраняет в `info` сдвиг `shift`
(нужен графику fig4 для реальных данных); на отбор и метрики не влияет.
