# Гипотеза «Ранняя остановка» (ветка research/hpo-early-stopping)

Записана 03.10.2026, **до** прогона с настоящими CatBoost / XGBoost / LightGBM и Optuna.

## Утверждение

В базовой настройке одна и та же выборка используется дважды: по ней останавливается обучение (выбирается число
деревьев) и по ней же Optuna считает оценку попытки. Из-за этого оценка получается заниженной (слишком хорошей).
Если останавливать обучение по отдельной выборке, самообман уменьшится, а качество на будущем не пострадает.

## Что меняем

Только выборку для ранней остановки:

| Режим | Остановка обучения | Оценка для Optuna |
|---|---|---|
| общая выборка (как в базе) | проверочная выборка V | V |
| отдельная выборка | отдельные 20% обучающих строк E | V |
| без остановки | нет; число деревьев подбирает Optuna | V |

## Критерий

Гипотеза **подтверждается**, если для режима «отдельная выборка» против «общей» (медиана по датасетам, моделям, отрезкам):

1. разрыв «будущее против проверки» меньше не менее чем на 3 процентных пункта;
2. ошибка на будущем не хуже более чем на 1%.

Режим «без остановки» — для сравнения: показывает, что даёт сама ранняя остановка.

## Запуск

```bash
python scripts/run_hpo.py --experiment h_early_stopping
python scripts/report_hpo.py --experiment h_early_stopping
```
