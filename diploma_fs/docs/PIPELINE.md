# Конвейер эксперимента

Один и тот же конвейер для всех методов и всех веток. **Меняется только шаг 4 (отбор).**
Поэтому любые два метода можно честно сравнивать: у них одинаковые данные, фолды,
модели и метрики.

```
1 загрузка ─► 2 разбиение ─► 3 модификации ─► 4 ОТБОР ─► 5 модели ─► 6 оценка ─► 7 сводка
 fsx/data.py   fsx/evaluate   fsx/transforms   fsx/selectors  fsx/evaluate  results/raw  scripts/report.py
```

## Шаги

| # | Шаг | Где | Что делает |
|---|---|---|---|
| 1 | Загрузка | `fsx/data.py` | Возвращает `Dataset(X, y, truth, time, meta)`. Встроенные: `synth_indep`, `synth_corr`, `diabetes`; любой CSV — `csv_dataset()` (`--csv --target [--time-col] [--sample]`). На этом шаге ничего не «учится» на данных. |
| 2 | Разбиение | `fsx/evaluate.py: make_splits` | Обычные данные: 5 фолдов × сиды 42/123/456 = 15 пар train/test. Временные (`time=True`): 10 блоков подряд без перемешивания, вокруг тестового блока из train убирается зазор 1% строк. |
| 3 | Модификации | `fsx/transforms.py: GroupFE` | Только по train: медиана для пропусков, сдвиг минимума к 1 (для log/sqrt/inv), список категорий. Каждый числовой фактор → группа из 5 вариантов `raw, log, sqrt, sq, inv` (словарь «фактор → варианты»). Категориальные → 0/1 и идут в модель мимо отбора. |
| 4 | **Отбор** | `fsx/selectors/*.py` | `f(F_train, y_train, groups, seed) -> (признаки, info)`. Каждый модуль объявляет `METHODS = {имя: f}` и подхватывается автоматически. |
| 5 | Модели | `fsx/evaluate.py: make_models` | Ridge (RidgeCV), MLP 32-16 (early stopping), HistGradientBoosting (300 итераций). Настройки **заморожены** и одинаковы для всех методов. |
| 6 | Оценка | `fsx/evaluate.py: run_method` | На test: R², MAE, RMSE, время обучения. Пишет `results/raw/<датасет>/<метод>.json`. |
| 7 | Сводка | `scripts/report.py` | Уилкоксон против `base_fe_all` + поправка Холма, вердикты ▲/▼/≈, рейтинг (Фридман, Неменьи), графики, `docs/REPORT.md`. |

Методы сейчас: `base_raw`, `base_fe_all`, `sysoev_paper`, `sysoev_fixed`,
`group_importance`, `shape_fit`, `boruta`, `rfe` (`python scripts/run.py --list`).

## Три правила честности

1. **Без утечки.** Всё, что подстраивается под данные (медианы, сдвиги, категории,
   сам отбор признаков), делается только на train-части фолда. Test видит только готовая модель.
2. **Меняется одно.** Данные, фолды, модели и их настройки одинаковы для всех методов;
   ветка меняет только шаг 4 (или добавляет датасеты). Подбор гиперпараметров моделей
   (ветка `research/optuna`) — отдельный эксперимент, в сравнение методов отбора не смешивается.
3. **Критерий заранее.** Правило «метод лучше / хуже» записано в `docs/DECISIONS.md`
   до прогона. Сравнение парное на одних и тех же фолдах, с поправкой на множественные
   сравнения; маленькая разница (< 0.005 R²) не считается выигрышем, даже если значима.

## Формат результата `results/raw/<датасет>/<метод>.json`

```json
{
 "dataset": "synth_indep", "method": "shape_fit",
 "truth": {"x1": "log", "x2": "sq", "x3": "inv", "x4": "sqrt"},   // null для реальных данных
 "n_rows": 1500, "n_base": 10,
 "passport": {"created": "2026-09-28T12:00:00", "git_commit": "47ada61",
              "python": "3.12.3", "packages": {"sklearn": "1.8.0", "...": "..."},
              "split": "kfold5x3", "dataset_meta": {}},
 "records": [                                   // один на пару train/test
  {"seed": 42, "fold": 0,
   "features": ["x1__log", "x2__sq", "x3__inv", "x4__sqrt"], "n_features": 4,
   "select_time": 0.45,
   "metrics": {"ridge": {"r2": 0.986, "mae": 0.24, "rmse": 0.30, "fit_time": 0.01},
               "mlp":   {"...": "..."}, "hgb": {"...": "..."}},
   "info": {}}                                   // что вернул метод; полностью — только для 1-го фолда
 ]
}
```

Имя признака: `<фактор>__<модификация>` (`x1__log`), категориальные — `<фактор>__cat_<значение>`.
Для временных данных `seed = 0`, `fold` = номер блока.

## Где что хранится

| Путь | Что | В git? |
|---|---|---|
| `fsx/` | код конвейера и методов | да |
| `scripts/` | `run.py`, `theory_check.py`, `report.py`, `check_env.py`, установка | да |
| `data/` | скачанные CSV | нет |
| `results/raw/` | JSON по фолдам | нет (воспроизводится `run.py`) |
| `results/theory_check.json`, `summary.csv`, `ranking.csv` | сводки | да (коммитите вы после прогона) |
| `results/figures/*.svg` | графики | да (коммитите вы после `report.py`) |
| `results/optuna/` | `studies.db` Optuna | нет |
| `docs/` | отчёт, методичка, план, решения | да |
