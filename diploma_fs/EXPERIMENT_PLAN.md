# План эксперимента: отбор признаков с учётом их модификаций

## Исследовательский вопрос

Как отбирать признаки, если каждый фактор представлен несколькими модификациями
(raw, log, sqrt, sq, inv), и зависит ли правильный способ от класса модели?

**Гипотеза H0 (теоретическая).** Монотонная трансформация признака не меняет разбиения
решающего дерева. Поэтому для бустинга выбор модификации не влияет на качество,
а для линейной модели и нейросети — влияет.

## Протокол (одинаков для всех веток)

| Что | Правило |
|---|---|
| Валидация | 5-fold CV × 3 сида (42, 123, 456) = 15 парных точек |
| FE и отбор | Только внутри train-части фолда (нет утечки отбора) |
| Модели оценки | Ridge (линейная), MLP (32-16), HistGradientBoosting |
| Гиперпараметры | Зафиксированы, одинаковы во всех ветках |
| Значимость | Парный тест Уилкоксона против `base_fe_all`, p < 0.05 |
| Метрики | R², число признаков, время отбора, стабильность (Жаккар), восстановление истины |

## Данные

| Датасет | Роль | Истина известна |
|---|---|---|
| `synth_indep` | 10 независимых факторов, 4 информативных | да: log(x1), sq(x2), inv(x3), sqrt(x4) |
| `synth_corr` | То же + каждый информативный коррелирует (0.8) с шумовым двойником | да |
| `diabetes` | Реальные данные, 442 × 10 | нет |

## Эксперименты (коммиты в этой ветке)

```
harness ── base_raw, base_fe_all (базовые линии)
├── Exp1 sysoev            алгоритм из статьи: буквально по псевдокоду + исправленный
├── Exp2 group_importance  групповая пермутационная важность, по одному представителю
├── Exp3 shape_fit         восстановление формы зависимости по PD аддитивной модели (аналог SHAP/EBM)
├── Exp4 boruta            Boruta: статистический тест против теневых признаков
└── Exp5 rfe               рекурсивное исключение (аналог CatBoost select_features)
```

Каждый эксперимент — один модуль в `fsx/selectors/`, подхватывается автоматически.
Сравнение и выводы: `python report.py` -> `REPORT.md`, `figures/`.

## Запуск

```bash
python run.py --method base_raw base_fe_all          # базовые линии
python run.py --method sysoev_paper sysoev_fixed     # и т.д. по экспериментам
python theory_check.py                               # проверка H0
python report.py                                     # таблицы, тесты, графики
```

## Перенос на CatBoost / SHAP (на своей машине)

| Здесь (scikit-learn) | У себя |
|---|---|
| GradientBoostingRegressor.feature_importances_ | CatBoost `get_feature_importance()` |
| partial dependence аддитивного HGB | `shap.TreeExplainer` + dependence plot / EBM (`interpret`) |
| собственная реализация Boruta | `BorutaShap` |
| RFE по пермутационной важности | `CatBoost.select_features(RecursiveByShapValues)` |
