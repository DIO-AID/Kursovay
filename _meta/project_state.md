# Состояние проекта

## Краткое описание
ML-пайплайн для исследования байесовской оптимизации гиперпараметров (TPE) на градиентном бустинге. Streamlit UI + Optuna + модульная архитектура.

## Архитектура
```
_meta/               # Служебная папка агента
_lessons/            # Найденные проблемы и уроки
app/                 # Streamlit UI + пайплайн
src/                 # Core ML модули
tuning/              # Optuna (search_spaces, tuner)
experiments/         # Batch эксперименты
orchestration/       # Оркестрация
configs/             # Конфиги
utils/               # Утилиты
Final/               # Честное сравнение Grid vs Optuna
data/                # Давайте
tuning/              # Optuna БД
статья/              # Статья Сысоева по SHAP-отбору
```

## Результаты (лучшие)
| Модель | Baseline R2 | Optuna 1000 R2 | Grid Search R2 |
|--------|-------------|----------------|----------------|
| XGBoost | 0.829 | 0.848 | 0.845 |
| LightGBM | 0.826 | 0.850 | 0.841 |
| CatBoost | 0.840 | 0.843 | 0.836 |

**Ключевое открытие:** Optuna не превосходит Grid по качеству, но в 9-11x быстрее.
