# Профиль пользователя

## Роль
- Разработчик ML-пайплайна
- Дипломник (тема связана с байесовской оптимизацией гиперпараметров)

## Цели
1. **Дипломная работа** — исследование поведения TPE (Optuna) в задачах градиентного бустинга
2. **Практический ML-пайплайн** — модульная система с Streamlit UI + аналитика
3. **Понимание математики TPE** — l(x), g(x), KDE, density ratio, exploration vs exploitation

## Интересы (из промтов и диалогов)
- Глубокая математика TPE, а не поверхностное использование Optuna
- Кастомная визуализация (не стандартные графики библиотек)
- Понимание "почему" — почему TPE выбирает одни параметры чаще
- Честное сравнение методов (Grid vs Optuna на одинаковых пространствах)
- Архитектура ML-систем (модульность, single responsibility)
- Работа с градиентным бустингом (XGBoost, LightGBM, CatBoost)

## Стек
- Python, Streamlit, Optuna, Scikit-learn
- XGBoost, LightGBM, CatBoost
- SHAP, SQLite, Pandas
- Windows (планирует переход на Arch Linux)
