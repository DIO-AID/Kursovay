# Направления дипломной работы — анализ

## Текущие темы в проекте

Твой проект охватывает **5 пересекающихся тем**. Вот они с оценкой дипломной перспективы:

---

### 🔷 Тема 1: Байесовская оптимизация (TPE) гиперпараметров

**Суть:** Исследовать как TPE (Tree-structured Parzen Estimator) работает — l(x), g(x), KDE, exploration vs exploitation. Не просто "подобрать параметры", а **понять поведение алгоритма**.

**Сильные стороны:**
- Есть математическая база (TPE — это не чёрный ящик)
- Есть Optuna + данные trial в SQLite
- Можно построить кастомную визуализацию (density ratio, эволюция распределений)
- Сравнение Grid vs Optuna уже сделано

**Риски:**
- Может уйти в чистую математику (руководитель-гуманитарий не оценит)
- Нужно глубоко разобраться в TPE (статья Bergstra et al. 2011)

**Вердикт:** ⭐ Сильная тема, если сделать акцент на **визуализации и интерпретации**

---

### 🔷 Тема 2: Сравнение методов оптимизации гиперпараметров

**Суть:** Grid Search, Random Search, Optuna (TPE), Hyperopt — сравнить по качеству, скорости, сходимости.

**Сильные стороны:**
- Практическая ценность — понятно всем
- Уже есть честное сравнение Grid vs Optuna
- Можно добавить Random Search как baseline

**Риски:**
- Избитая тема (сотни статей)
- Grid Search на бустинге — долгий (CatBoost: 46 минут на 864 комбинации)
- Результат предсказуем: Optuna быстрее, Grid точнее

**Вердикт:** ⚠️ Слабая тема для диплома — мало новизны

---

### 🔷 Тема 3: Feature Engineering vs Feature Selection (SHAP + мультиколлинеарность)

**Суть:** Модифицированный алгоритм Сысоева: SHAP-отбор для устранения мультиколлинеарности при Feature Engineering. Доказать что SHAP-отбор восстанавливает R² после FE.

**Сильные стороны:**
- Есть готовая статья Сысоева (научная база)
- Есть результаты: FE(173) R²=0.8266 → SHAP(8) R²=0.8360 (+0.94%)
- Конкретная проблема (мультиколлинеарность) и конкретное решение (SHAP)
- Хорошо ложится в формат "проблема → решение → эксперимент → вывод"

**Риски:**
- Описательная статистика, не глубокая математика
- SHAP — это уже стандарт, новизна только в модификации

**Вердикт:** ⭐ Сильная тема, если оформить как "Модифицированный алгоритм отбора признаков на основе SHAP"

---

### 🔷 Тема 4: Разработка ML-пайплайна с Streamlit

**Суть:** Спроектировать и реализовать модульную систему для экспериментов с ML-моделями.

**Сильные стороны:**
- Есть работающий код
- Реальная инженерная работа

**Риски:**
- Это **инженерный проект**, а не научное исследование
- Для диплома по ML слабовато
- Не отвечает на вопрос "что нового?"

**Вердикт:** ❌ Не подходит как основная тема диплома

---

### 🔷 Тема 5: Комплексное исследование (TPE + SHAP + Pipeline)

**Суть:** Объединить всё: TPE-оптимизация → отбор SHAP → оценка на пайплайне → анализ поведения TPE на отобранных признаках.

**Сильные стороны:**
- Охватывает полный цикл ML-исследования
- Каждая часть даёт результаты для анализа

**Риски:**
- Слишком широко — поверхностно по каждой теме
- Риск "галопом по европам"
- Сложно защитить: вопросы по каждой части

**Вердикт:** ⚠️ Только если сфокусироваться на связи TPE + SHAP

## Моя рекомендация

**Лучшая тема: Тема 1 (TPE) с акцентом на визуализацию**

Почему:
1. У тебя уже есть все данные (trial в SQLite)
2. Есть интерес к математике TPE (l(x), g(x), KDE)
3. Можно сделать реально новый вклад — **кастомная система визуализации TPE**, которой нет в стандартных библиотеках
4. Хорошо ложится в формат: теория TPE → реализация → визуализация → эксперименты → выводы

**Название (набросок):**
> *«Исследование поведения байесовской оптимизации гиперпараметров (TPE) методами визуализации плотностей распределения»*

**Запасной вариант: Тема 3 (SHAP + мультиколлинеарность)**
- Более прикладная, понятная
- Меньше математики, больше практики

## Что нужно решить

1. **Математика или практика?** TPE — глубокая математика, SHAP — прикладная задача
2. **Объём:** Одна модель (например XGBoost) или все три?
3. **Визуализация:** Как часть диплома или как отдельное приложение?
4. **Новизна:** Что именно ты делаешь нового (не просто "применил Optuna")?
