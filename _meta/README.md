# _meta — служебная папка AI-агента

## Назначение
Хранение контекста работы: кто пользователь, состояние проекта, задачи, направления развития.

## Структура

| Файл | Содержание |
|------|-----------|
| `user_profile.md` | Информация о пользователе: цели, интересы, стек, роли |
| `project_state.md` | Текущее состояние ML-проекта, архитектура, результаты |
| `tasks.md` | Активные задачи и прогресс |
| `directions.md` | Направления развития диплома |
| `references/` | Ссылки на промты, структуру, ключевые файлы |

## Принципы
- Файлы обновляются по мере работы
- Не удалять без явной необходимости
- Использовать как контекст для будущих сессий
