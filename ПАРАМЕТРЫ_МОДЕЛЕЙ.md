# Параметры моделей машинного обучения

## XGBoost (9 основных параметров)

| Параметр | Тип | Диапазон | Суть | Для чего |
|----------|-----|----------|------|----------|
| `n_estimators` | int | 100-1000 | Кол-во деревьев | Больше = сложнее модель, риск переобучения |
| `max_depth` | int | 4-10 | Макс. глубина дерева | 6-10 обычно оптимально |
| `learning_rate` | float | 0.01-0.1 (log) | Скорость обучения | Маленький = медленнее, но точнее |
| `subsample` | float | 0.6-1.0 | Доля данных для дерева | 0.6-0.9 — уменьшает переобучение |
| `colsample_bytree` | float | 0.6-1.0 | Доля признаков для дерева | 0.6-0.9 — фиче selection |
| `min_child_weight` | int | 1-10 | Мин. сумма весов в листе | Больше = консервативнее |
| `gamma` | float | 0-3 | Минимальное снижение loss | Больше = меньше сплитов |
| `reg_alpha` (L1) | float | 1e-4 - 10 (log) | L1 регуляризация | Sparse solutions — отбор признаков |
| `reg_lambda` (L2) | float | 1e-4 - 10 (log) | L2 регуляризация | Стабильность, anti-overfit |

### Дополнительные параметры XGBoost

| Параметр | Тип | Суть | Для чего |
|----------|-----|------|------|----------|
| `scale_pos_weight` | float | Баланс классов | Для imbalanced данных |
| `objective` | categorical | Функция потерь | reg:squarederror, reg:pseudohubererror |
| `booster` | categorical | Тип бустера | gbtree, gblinear, dart |
| `colsample_bylevel` | float | Кол-во фичей на уровень | Альтернатива colsample |
| `colsample_bynode` | float | Кол-во фичей на узел | Альтернатива colsample |
| `delta` | float | Huber delta | Для pseudohubererror |
| `eta` | float | Синоним learning_rate | Тоже самое |
| `max_bin` | int | Макс. бинов | Для hist tree method |
| `tree_method` | categorical | Метод построения | hist, gpu_hist, auto |

## Рекомендации по выбору параметров

### Приоритет 1 (всегда влияет):
1. `n_estimators` / `learning_rate` — компромисс
2. `max_depth` / `num_leaves` — сложность модели
3. `learning_rate` — точность

### Приоритет 2 (регуляризация):
1. `subsample` / `colsample_bytree` — anti-overfit
2. `reg_lambda` — стабильность
3. `reg_alpha` — sparse solutions

### Приоритет 3 (дополнительно):
1. `min_child_weight` — консервативность
2. `gamma` / `min_gain_to_split` — контроль сплитов
3. `bagging_temperature` — рандомизация

## Математика регуляризации

### L1 (Lasso) — `reg_alpha`
```
Loss = Loss_original + α * Σ|wi|
```
- Штрафует большие веса
- Приводит к sparse решениям (многие wi → 0)
- Использовать когда много признаков

### L2 (Ridge) — `reg_lambda`
```
Loss = Loss_original + λ * Σwi²
```
- Штрафует большие квадраты весов
- Стабильнее чем L1
- Стандартный выбор

### ElasticNet — комбинация L1 + L2
```
Loss = Loss_original + α * Σ|wi| + λ * Σwi²
```
- Лучшее от обоих миров
- `l1_ratio` контролирует баланс

## Early Stopping

Все модели поддерживают early stopping:
- XGBoost: `early_stopping_rounds`
- LightGBM: `callbacks=[lgb.early_stopping(...)]`
- CatBoost: `early_stopping_rounds`

**Зачем:** экономит время, не обучает лишние итерации.
