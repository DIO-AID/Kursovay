# Контекст проекта: Курсовая НИС

## Описание
Курсовая работа по НИС (научно-исследовательская работа). 
Сравнение моделей машинного обучения (XGBoost, LightGBM, CatBoost) 
с Optuna-оптимизацией гиперпараметров на датасете Housing.

## Структура проекта
- `src/` — исходный код моделей
- `experiments/` — эксперименты и логи
- `configs/` — конфигурации моделей
- `data/` — данные (Housing dataset)
- `app/` — приложение/интерфейс
- `Final/` — финальные результаты
- `tuning/` — Optuna tuning
- `utils/` — утилиты
- `orchestration/` — оркестрация пайплайнов
- `catboost_info/` — логи CatBoost
- `статья/` — материалы для статьи
- `prompt-repos-questionnaire.md` — описание проекта

## Технологии
- Python, scikit-learn, XGBoost, LightGBM, CatBoost
- Optuna для гиперпараметрической оптимизации
- Работа с БД SQLite для хранения результатов Optuna

## Текущая задача
Сравнение моделей с разным количеством итераций Optuna (100 vs 1000)
и анализ переобучения.
